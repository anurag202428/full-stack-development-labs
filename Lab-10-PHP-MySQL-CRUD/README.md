# Lab Sheet 10 — PHP + MySQL
Demonstrates a PDO connection to MySQL, fetching student rows, inserting a student, and deleting a student using prepared statements and escaped output.

## Setup (XAMPP)
1. Start Apache and MySQL.
2. Open phpMyAdmin and import `database.sql`.
3. Place this folder inside `htdocs` (or serve with PHP CLI).
4. Check local credentials in `config.php`.
5. Visit `http://localhost/Lab-10-PHP-MySQL-CRUD/`.

This is a local classroom sample. Keep credentials out of public repositories in real deployments. The included defaults are common local XAMPP defaults, not production settings.
