# Lab Sheet 8 — Django Student Lists
Objective: display selected student data in ordered and unordered lists using a Django view and template.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Open `http://127.0.0.1:8000/`. Student details are sample data in `students/views.py`.
